## 2. 핵심 구현 내역
1. **헤더 & GNB (`.site-nav`)**:
   - 블러(Backdrop blur) 처리된 모던 스티키 네비게이션
   - 시스템/수동 전환 다크 모드 토글 버튼 및 브런치 이동 아웃링크
2. **히어로 섹션 (`.hero-section`)**:
   - 고해상도 원형 아바타, 3대 전문 뱃지(제품기획자, 소설가, 웹서비스 빌더)
   - 시그니처 카피: *"기획의 ‘본질’, 사용자의 ‘관점’, 그리고 인간의 ‘한계’에 대해 관심이 많습니다. 그에 관한 글도, 소설도, 웹 서비스도 만듭니다."*
   - 핵심 지표 4종(경력 12년, 브런치 193편, 소설 3작품, 인터랙티브 웹서비스)
3. **삼각 기둥 하이라이트 (`.pillars-section`)**:
   - 글(브런치 연재) / 소설(문피아 3작품) / 웹서비스(Dr. Brooks Services) 카드 및 다이렉트 액션
4. **인터랙티브 탭 시스템 (`.tabs-section`)**:
   - 전체(All), 글 & 생각(Essays), 소설(Novels), 웹서비스(Services), 소개(About)
   - 모바일 스크롤 지원 및 URL 해시(`window.location.hash`) 동기화
5. **소설 쇼케이스 카드 (`.novel-card`)**:
   - <초강마패>, <이산화탄소 조직>, <우블리에트의 파수꾼> 표지 썸네일, 장르/화수 뱃지, 로그라인, 문피아 읽기 링크
6. **웹 서비스 카드 (`.service-card`)**:
   - Dr. Brooks Services 주요 기능 체크리스트, 기술 스택 태그, 실시간 방문 링크
7. **무결점 자립 실행성 (Zero-Dependency)**:
   - 외부 프레임워크나 복잡한 빌드 도구 의존성 없이 단일 정적 웹으로 실행 가능.
   - 로컬 `file://` 실행 및 Cloudflare Pages, GitHub Pages, Vercel 등 어디서든 즉시 배포 가능.
