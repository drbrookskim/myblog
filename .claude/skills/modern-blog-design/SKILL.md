# Modern Blog Design Skill

닥터브룩스 블로그의 에디토리얼 감성과 프로덕트 지향적 UI/UX를 구현하는 모던 웹 디자인 스킬이다.

## 핵심 디자인 원칙

1. **지적 미니멀리즘 (Intellectual Minimalism)**
   - 군더더기 없는 레이아웃과 넉넉한 호흡(Whitespace)
   - 서체: 가독성이 뛰어난 산세리프(Pretendard/Inter)와 문학적 감성의 세리프/명조 액센트의 조화
   - 포인트 컬러: 깊이감 있는 딥 네이비/인디고, 슬레이트 그레이, 우아한 틸(Teal/Emerald) 포인트

2. **완벽한 다크/라이트 모드 지원**
   - CSS 커스텀 속성(`--bg`, `--surface`, `--text-primary`, `--text-secondary`, `--border`, `--accent`)을 통한 테마 시스템
   - 시스템 설정(`prefers-color-scheme`) 자동 감지 및 사용자 수동 토글 영구 저장(`localStorage`)

3. **3개 축 중심의 탭/필터 내비게이션**
   - **전체 (All)**: 하이라이트 요약 대시보드
   - **글 & 생각 (Essays)**: 브런치 193편의 글과 기획 인사이트 아카이브
   - **소설 (Novels)**: <초강마패>, <이산화탄소 조직>, <우블리에트의 파수꾼> 등 문학적 쇼케이스
   - **웹서비스 (Services)**: Dr. Brooks Services 포털 및 개발된 프로덕트 카탈로그
   - **소개 (About)**: 12년차 기획자의 철학과 배경 이야기

4. **반응형 최적화**
   - 모바일(360px ~ 480px), 태블릿(768px), 데스크톱(1024px ~ 1280px) 전 구간 유연한 그리드 레이아웃
   - 터치 친화적 타깃(44px 이상)과 모바일 햄버거/바텀 탭 내비게이션 지원

## UI 컴포넌트 구조
- **Header**: 로고, 프로필 미니 아바타, 탭 네비게이션, 테마 토글 버튼
- **Hero Banner**: "안녕하세요. 닥터브룩스입니다." 핵심 철학을 보여주는 시그니처 인트로
- **Identity Cards (3 Pillars)**: 글 / 소설 / 웹서비스 3개 축을 시각적으로 상징하는 카드
- **Dynamic Content Grid**: 선택된 탭에 따라 카드/리스트 형태로 렌더링되는 인터랙티브 피드
- **Novels Showcase**: 소설 표지, 장르 태그, 로그라인, 문피아 바로가기 링크 버튼
- **Services Showcase**: 서비스 설명, 기술 스택 뱃지, 실시간 데모 바로가기 링크
- **Footer**: 카피라이트, 브런치/문피아/깃허브/X 링크 아웃

## 구현 체크리스트
- 시맨틱 태그(`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) 준수
- 외부 의존성(Heavy Framework) 없이 순수 HTML/CSS/JS로 가볍고 신속한 로딩 보장
- 코드 수정 후 브라우저 렌더링 확인
